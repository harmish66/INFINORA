# INFINORA

Infinora is a professional, high-performance creative studio application featuring an unlimited infinite canvas and infinite zoom capabilities. Built with Flutter, Riverpod, and clean architectural patterns.

## Features

- **Infinite Drawing Canvas**: Vector and raster drawing on an unlimited coordinate plane with subpixel precision.
- **Infinite Zoom Engine**: Deep-scale nested artwork navigation with focal-point invariance.
- **Curated Template Library**: Over 60 templates across 18 creative categories (Mandala, Zentangle, Doodle, Mind Maps, Infinite Zoom, and more).
- **Multi-Layer Studio System**: Layer management with visibility, lock controls, opacity, and reordering.
- **Selection & Transform Toolbar**: Scale, rotate, translate, flip, and adjust z-index of canvas objects.
- **Production Monetization**: Non-intrusive AdMob monetization with strict frequency capping, native sponsored cards, and an ad-free creative canvas environment.
- **Cross-Platform**: Support for Android, iOS, macOS, Windows, Linux, and Web.

## Getting Started

### Prerequisites

- Flutter SDK (v3.24 or newer)
- Dart SDK (v3.5 or newer)

### Installation

```bash
flutter pub get
flutter run
```

### Run Tests

```bash
flutter test
```
